# Duplicate Sermons Report

This report lists sermon files whose CONTENT substantially duplicates another sermon file, grouped so you can decide what to keep and what to remove. The groups were found by extracting every `## Overview` paragraph from the sermon files and running 5-gram and 8-gram containment scans over the transcripts and sermon files. The report also lists same-topic files that are deliberately not treated as duplicates, data defects found in the library, sermon files missing template sections, and summary counts.

How To Read This Report:

- **Keep / Remove Candidate** names the most complete member of each group (usually the longest and most fully templated file). It is a recommendation to weigh, not an automatic delete instruction.
- **Shared Content / Nature of the Overlap** describes what the files have in common and how it was measured: verbatim 8-gram or 5-gram containment, byte-identical transcripts, shared or translated steps, and shared examples.
- **Key Differences** explains why files in the same group are not interchangeable. Read it before deleting anything, because some groups hold partial re-uploads, highlight cuts, or genuinely different recordings on one theme.
- Rows in **Near Duplicates and Thematic Overlaps** are same-topic files that are NOT duplicates and are listed only so they are not mistaken for duplicates.
- Every file path in this report was verified against the repository before publication.
