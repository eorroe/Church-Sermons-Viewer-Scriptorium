# Duplicate Sermons

Scan of the entire `/workspace/app` directory found **214 `.md` files**. Of these, **212 follow the sermon-template.md structure** (141 contain all template sections including Security & Safety Notes; 71 contain every section except Security & Safety Notes). Two sermon files are Spanish-language translations of sermons (`Nuevas Opportunidades.md`, `Deshazte de Estos Pecados Sexuales.md`) that follow the template with translated section headers. No two files are byte-identical.

**7 duplicate sermon groups** were identified, covering **16 files**. Each group below shares the same source sermon / core teaching, scripture, and instructions. Differences are described so you can decide which copy to keep.
